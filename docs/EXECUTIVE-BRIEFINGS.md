# Executive Briefings

Each completed Harbor Health mission closes with two executive-facing artifacts:

- a one-page brief designed to be read in about 90 seconds;
- a short slide deck for a leadership discussion.

The technical work stays in the repository. These briefings explain the problem, evidence, decision, solution, implementation plan, impact, risks, and next step without requiring the reader to inspect the code first.
