# Executive Briefings

Each solved Harbor Health problem closes with two executive-facing artifacts:

- a one-page brief designed to be read in about 90 seconds;
- a short leadership deck.

The technical work stays in the repository. These briefings explain the problem, evidence, decision, solution, implementation, adoption, results, risks, and next step without requiring the reader to inspect the code first.
