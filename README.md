## What Solutions Lab is

Solutions Lab trains a single higher-order capability:

**Enter an unfamiliar environment, establish what is true, diagnose the right problem, work across business and technology, build a defensible solution, and verify what changed.**

The operating loop is:

**Discover → Establish Reality → Diagnose → Design → Build → Test → Deploy → Verify → Improve**

Technical skills are developed inside increasingly complex engagements that can require SQL, Python, APIs, integrations, AI, automation, architecture, reliability, workflow redesign, or a combination of them.

## What this project demonstrates

- Designing learning systems around transfer, not checklist completion
- Building realistic operating environments where ambiguity and constraints matter
- Evaluating technical judgment through evidence, not self-reported confidence
- Connecting implementation, product, engineering, operations, and executive reasoning
- Treating deployed behavior and observed outcomes as the real test of a solution

## Standard

A capability is not considered demonstrated because it was explained correctly once. The standard is the ability to understand the problem, produce working evidence, explain the reasoning, and transfer the capability when the environment changes.

**Working systems and demonstrated judgment > checklist completion.**
